YouTube API 키 넣기 (무료, 처음 한 번)
  1. 여기 눌러 YouTube Data API v3 열기 ↗ → 구글 로그인 → 프로젝트 고르기(없으면 새로 만들기) → 파란 사용 버튼
  2. 사용자 인증 정보 열기 ↗ → 위쪽 + 사용자 인증 정보 만들기 → API 키 → 나온 키 복사
  3. 아래 칸에 붙여넣고 저장하고 확인. Gemini 키와 같은 프로젝트라면 Gemini 키에 YouTube를 "사용"으로 켜기만 해도 돼요.
무료로 하루 약 10,000점까지 써요. 한 번 찾기에 약 200점 → 하루 40~50번 찾을 수 있어요. 같은 조건은 6시간 동안 저장해 두고 점수를 안 써요. 매일 오후 4~5시(한국시간)에 다시 채워져요.

영상 타입
올라온 기간
구독자 구간
정렬
떡상지수 = 조회수 ÷ 구독자 수. 10배 이상이면 구독자가 적어도 알고리즘이 밀어준 영상이에요. 이런 영상의 첫 문장·제목·주제를 참고해 내 스타일로 새로 만드세요. 영상·대본을 그대로 베끼면 저작권 신고로 채널이 위험해져요.
