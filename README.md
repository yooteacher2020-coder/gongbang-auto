# 쇼츠공방 자동화 (gongbang-auto)

쿠팡 파트너스로 수익을 내는 **쇼핑 쇼츠 자동화 웹**입니다.

| 기능 | 설명 |
|---|---|
| 🔥 상품 찾기 | 쿠팡 **3일 베스트**(매일 순위 저장 → 3일 합산), 카테고리 베스트, 골드박스, 키워드 검색 |
| 🔢 상품번호 | 영상 속 “상품번호 N” ↔ 쿠팡 파트너스 링크 연결. `/go/N` 으로 바로 이동 + 클릭 수 집계 |
| 🛍️ 시청자 페이지 | `/shop` — 시청자가 번호를 입력하면 쿠팡 상품으로 이동 (채널 프로필 링크에 걸기) |
| 🎥 영상 만들기 | 선택한 상품으로 1080×1920 쇼츠 자동 생성 (TOP N 랭킹 / 단일 상품), 배경음악, 상품번호 배지, 쿠팡 파트너스 고지 문구 자동 삽입 |
| 📝 업로드 문구 | 제목·설명란·고정 댓글 자동 생성 (상품별 `/go/N` 링크 + 대가성 문구 포함) |

## 왜 “상품번호 → 쿠팡” 이 이렇게 동작하나요?
유튜브 쇼츠는 영상 속 글자를 누를 수 없고, 설명란·댓글 링크도 쇼츠에서는 눌리지 않습니다. 그래서 쇼핑 쇼츠는 보통
**채널 프로필 링크(클릭 가능) → 상품번호 검색 페이지 → 쿠팡** 구조를 씁니다.
이 웹의 `/shop` 페이지가 그 역할을 하고, `/go/번호` 가 쿠팡 파트너스 링크로 이동시키면서 클릭 수를 셉니다.

## 배포 (Netlify)
1. Netlify → **Add new site → Import from Git** → 이 저장소 선택 (빌드 설정은 `netlify.toml` 이 자동 적용)
   - 기존 사이트(shortsgongbang-yoo)를 그대로 쓰려면 그 사이트의 *Site configuration → Build & deploy → Link repository* 에서 이 저장소를 연결하세요.
2. *Site configuration → Environment variables* 에 추가 (`.env.example` 참고)
   - `ADMIN_PASSWORD` — 관리자 비밀번호 (**꼭 설정**. 없으면 누구나 상품을 수정할 수 있음)
   - `COUPANG_ACCESS_KEY`, `COUPANG_SECRET_KEY` — 쿠팡 파트너스 → 추가기능 → 오픈 API
   - `COUPANG_SUB_ID` (선택) — 채널별 수익 구분용
   - `SNAPSHOT_CATEGORIES` (선택) — 3일 베스트를 수집할 카테고리 ID
3. 배포 후 사이트 → ⚙️ 설정 탭에서 관리자 비밀번호 입력 → “오늘 순위 지금 저장”
4. YouTube 스튜디오 → 맞춤설정 → 기본 정보 → 링크에 `https://내사이트/shop` 추가

> 쿠팡 오픈 API 키는 파트너스 **최종 승인 + 누적 판매 실적 조건**을 채운 뒤 발급됩니다.
> 키가 없을 때는 **샘플 모드**로 동작하며, ‘상품번호’ 탭에서 파트너스 사이트의 *링크 생성* 으로 만든 단축 URL을 직접 등록하면 됩니다. (번호·링크·영상 기능은 모두 정상 동작)

## 3일 베스트는 어떻게 계산하나요?
쿠팡 API는 판매량 숫자를 주지 않습니다. 대신 **매일 오전 10시(KST)** 카테고리별 베스트 순위(최대 50위)를
Netlify Blobs 에 저장하고, 최근 3일 동안 **며칠 상위권에 있었는지 → 순위 점수 합** 순으로 정렬합니다.
3일 연속 상위권 = 꾸준히 잘 팔리는 상품입니다. 처음 3일 동안은 쌓인 날짜만큼만 합산됩니다.

## 로컬 실행 / 테스트
```bash
npm install
npm test          # API 단위 테스트
npm run local     # http://localhost:8888 (Netlify 없이, 데이터는 .data/ 폴더)
```

## 구조
```
public/            화면 (index.html 스튜디오, shop.html 시청자용, video.js 영상 렌더러)
netlify/functions/ 서버 API
  coupang.mjs        /api/coupang   쿠팡 API (베스트/골드박스/검색/3일 베스트/딥링크)
  products.mjs       /api/products  상품번호 등록·수정·삭제
  go.mjs             /go/:no        파트너스 링크로 이동 + 클릭 수
  img.mjs            /api/img       쿠팡 이미지 프록시 (영상 녹화용 CORS)
  snapshot-daily.mjs 매일 베스트 순위 저장 (스케줄 함수)
```
