핸드폰에 앱처럼 깔기

안드로이드크롬 추천
PC크롬·엣지 추천
아이폰사파리 최신 버전 · 되는지 꼭 알려주세요

  1. 받은 주소 열기

    운영자가 카톡으로 보낸 주소(예: yooteacher2020-coder.github.io/gongbang-auto)를 누르세요. 안드로이드는 크롬, 아이폰은 사파리로 열리게 해주세요. 카톡 안에서 열렸다면 오른쪽 위 메뉴에서 "다른 브라우저로 열기"를 누르세요.

  2. 홈 화면에 추가

    안드로이드 크롬: 오른쪽 위 ⋮ → 홈 화면에 추가 또는 앱 설치
    아이폰 사파리: 아래 가운데 공유 □↑ → 홈 화면에 추가
    이제 바탕화면의 쇼츠공방 아이콘으로 바로 들어가요. PC는 주소창 오른쪽 설치 아이콘을 누르면 돼요.

  3. 무료 AI 키 받기 (선택, 3분)

    AI 대본과 AI 목소리를 쓰려면 필요해요. 없어도 "AI 없이 바로 만들기"로 영상은 만들 수 있어요.
    ① aistudio.google.com/apikey 접속 → 구글 계정으로 로그인
    ② API 키 만들기(Create API key) 누르기 → AQ.… 또는 AIza…로 시작하는 키를 복사 아이콘으로 복사
    ③ 쇼츠공방 오른쪽 위 설정 → 키 붙여넣기 → 키 확인에 ✅가 뜨면 끝

  4. 영상 하나 만들어 보기

    화면 아래 다음만 누르면서 따라가요.
    ① 상품 이름·고민·장점 적기 → ② AI로 대본 3개 쓰기 후 마음에 드는 안 고르기 → ③ 상품 쓰는 장면 사진·영상 3~6개 넣기 → ④ 목소리·음악 고르기 → ⑤ 영상 만들기

  5. 저장하고 올리기

    완성되면 영상 저장(폰은 공유로 유튜브 앱에 바로 보낼 수 있어요). 아래 업로드 패키지의 제목, 설명, 고정댓글을 복사해서 붙여넣으세요.

영상 만드는 동안에는 화면을 켜두고 앱에 머물러 주세요. 30초 영상은 약 30초 걸려요. 다른 앱으로 넘어가면 영상이 멈출 수 있어요.
소재 저작권: 다른 사람의 틱톡·유튜브 영상을 그대로 쓰면 신고로 채널이 위험해질 수 있어요. 직접 찍은 영상이나 판매자가 허락한 소재로 테스트해 주세요.
운영자용 · 처음 한 번, 10분

상품번호 → 쿠팡 바로 연결하기

유튜브는 쇼츠의 설명란·댓글 링크를 누를 수 없게 막아 두었어요. 그래서 시청자가 "상품번호 12번"을 봐도 살 방법이 없었어요. 이제 채널 프로필 링크 → 상품 찾기 페이지 → 번호 누르기 → 쿠팡 순서로 바로 갈 수 있어요. 영상을 만들 때마다 번호와 링크가 찾기 페이지에 자동으로 올라가요.

  1. 자동 올리기 열쇠(토큰) 만들기

    쇼츠공방 설정 → 토큰 만들러 가기 (GitHub 로그인)
    ① Token name: 쇼츠공방 · Expiration: 가장 긴 기간
    ② Repository access: Only select repositories → gongbang-auto 선택
    ③ Permissions → Repository permissions → Contents → Read and write
    ④ 맨 아래 Generate token → github_pat_… 복사
    이 열쇠는 이 저장소에만 쓸 수 있어요. 다른 사람에게 보내지 마세요.

  2. 쇼츠공방에 넣기

    설정 → 토큰 붙여넣기 → 연결 확인에 ✅가 뜨면 끝. 이 기기에 있던 상품 목록이 바로 올라가요. PC와 폰을 둘 다 쓰면 각 기기에 한 번씩 넣어주세요.

  3. 예전 영상 링크 채우기

    내 상품 → 번호마다 쿠팡 파트너스 링크(link.coupang.com/a/…)를 붙여넣기. 목록에 없는 예전 영상은 + 번호 추가. 닫으면 자동으로 올라가요. 일반 쿠팡 주소(coupang.com/vp/…)는 수수료가 안 붙으니 꼭 파트너스에서 만든 링크를 넣어주세요.

  4. 채널 링크 맨 위에 등록

    PC: 유튜브 스튜디오 → 맞춤설정 → 프로필 → 링크 추가 → 제목 상품번호로 찾기 👈, URL은 설정의 상품 찾기 페이지 주소 → 맨 위로 끌어올리기 → 게시
    폰: 유튜브 앱 → 내 채널 → 연필 아이콘 → 링크
    인스타·틱톡·스레드도 프로필 편집 → 링크에 같은 주소를 넣어주세요.

  5. 영상 올릴 때

    영상 끝에 "상품번호 N번, 프로필 링크에서 찾아보세요"가 자동으로 나와요. 업로드 패키지의 설명란·고정댓글을 그대로 붙여넣으면 돼요. 스레드·블로그처럼 링크를 누를 수 있는 곳에는 바로가기 주소(…shop.html?n=12)를 쓰면 누르자마자 쿠팡으로 가요.

올린 뒤 1분쯤 지나면 찾기 페이지에 보여요. 설정의 열어보기로 직접 번호를 눌러 쿠팡이 열리는지 꼭 한 번 확인해 보세요.
구독자 1만 명이 넘어 유튜브 쇼핑 제휴 프로그램에 들어가면 업로드할 때 제품 태그도 달 수 있어요. 쇼츠 화면에 "제품 보기" 버튼이 생겨 가장 잘 팔려요.

앱을 인터넷에 올리고 주소 만들기

받은 쇼츠공방 압축파일을 무료 사이트(넷리파이)에 올리면, 누구나 열 수 있는 주소가 생겨요. 그 주소를 테스터 3명에게 보내면 끝이에요.

  1. 업로드용 압축파일 준비

    받은 shortsgongbang_upload.zip을 압축을 풀지 말고 바탕화면에 그대로 저장해 두세요.

  2. 넷리파이 가입

    app.netlify.com/signup 접속 → Sign up with Google으로 구글 계정 가입 (무료). 질문이 나오면 아무거나 고르고 넘어가도 돼요.

  3. 폴더 끌어다 놓기

    app.netlify.com/drop 접속 → 화면의 점선 상자 안에 shortsgongbang_upload.zip 파일을 끌어다 놓기 (폴더는 안 받아요). 몇 초 뒤 어쩌고-12345.netlify.app 같은 주소가 생겨요.

  4. 주소를 쉬운 이름으로 바꾸기

    Site configuration → Change site name → 예: shortsgongbang-yoo 입력 → 주소가 shortsgongbang-yoo.netlify.app이 돼요.

  5. 내 폰에서 먼저 열어보기

    그 주소를 내 카톡으로 보내 폰에서 열고, 위 테스터용 순서대로 한 번 해보세요. 잘 되면 테스터 3명에게 주소와 이 안내 페이지를 보내주세요.

새 버전으로 바꿀 때: 넷리파이에서 내 사이트 → Deploys 탭 → 새 업로드용 zip 파일을 다시 끌어다 놓기. 주소는 그대로이고, 테스터 앱도 자동으로 새 버전이 돼요.
AI 키는 각자 따로: 키는 각 사람의 기기에만 저장되고 서로 공유되지 않아요. 무료 한도도 사람마다 따로라서 테스터마다 자기 키를 받는 게 좋아요.
